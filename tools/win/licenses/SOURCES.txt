Third-party programs in this folder, and where their source code is
====================================================================

app\toolchain\sh-elf   GCC 13.3.0 and GNU binutils 2.42, built for Windows
                       (target sh-elf) with toolchain-build_win_sh.sh from the
                       unmodified upstream releases:
                         gcc-13.3.0.tar.xz, binutils-2.42.tar.xz,
                         gmp-6.3.0, mpfr-4.2.1, mpc-1.3.1
                       https://ftp.gnu.org/gnu/  (licence: GPL-3.0.txt, with the
                       GCC Runtime Library Exception for libgcc).  If you pass
                       this folder on to others, offer them these source
                       archives too (the GPL asks for that).
app\emu\snes9x_libretro.dll
                       snes9x (libretro core), https://github.com/libretro/snes9x
                       plus snes9x-trace.patch (snapshot hooks used by the
                       capture step).  Licence: snes9x-LICENSE.txt
                       (free for non-commercial use).
app\emu\harness.exe    our own small loader for the core: app\tools\emu\harness.c
app\runtime\python     Python 3.12 (python-build-standalone), PSF licence
                       (app\runtime\python\LICENSE.txt); numpy 1.26 (BSD) and
                       Pillow (HPND), licences in their *.dist-info folders.
